Get started

Install Grinch, write one rule, and make it your default browser. Every step can be undone.

  1. Install Grinch

    Grinch needs macOS 13 or later. Releases are universal binaries for Apple silicon and Intel Macs, signed with a Developer ID and notarized by Apple.

    Download the latest Grinch-vX.Y.Z.dmg from the releases page, open it, and drag Grinch.app onto the Applications shortcut in the DMG window.

    Install to /Applications directly. Running Grinch.app from ~/Downloads or anywhere else triggers Gatekeeper translocation, which makes the same app appear several times in the default-browser picker.

  3. Launch Grinch

    Open Grinch from Applications. Its eyes appear in the menu bar. Click them for Open Config, Reload Config, Open Diagnostic Log, and update checks. The menu bar reference lists every item.

    macOS also asks whether Grinch may use Accessibility. Grinch only needs it for rules that read the title of the window a link came from. You can decline now and allow it later under System Settings → Privacy & Security → Accessibility.

  4. Make Grinch your default browser

    Open System Settings → Desktop & Dock → Default web browser and choose Grinch. Links you open in other apps now go through your rules.

Change your config

Edit the file, then choose Reload Config (⌘R) from the menu. If the reload fails, the menu-bar icon changes to a warning sign and the menu shows the error. Grinch keeps routing with the last config that loaded until you fix it.

To check a config from a terminal or an editor save hook, run Grinch --validate. If your edits don't take effect, Grinch may be reading a different config file.

Updates

Grinch checks for updates once a day. To check now, choose Check for Updates… from the menu bar. Turn off Check for Updates Automatically in the same menu, or set checkForUpdates: false in your config, to stop the daily check.

Undo or uninstall

To stop routing links through Grinch, choose another browser under System Settings → Desktop & Dock → Default web browser.

To remove Grinch:

  1. If you turned on Start at Login, turn it off in the Grinch menu.
  2. Choose Quit Grinch (⌘Q).
  3. Move /Applications/Grinch.app to the Trash.

Your config file and the logs in ~/Library/Logs/Grinch/ stay until you delete them.

Getting help

Only the latest published release is supported for issues and security fixes. Upgrade and reproduce the problem before filing a bug; older releases don't receive backported fixes.

For bug reports and feature requests, follow the contributor guide. Report suspected vulnerabilities through private reporting, not a public issue. The security policy explains what to include and how to redact diagnostics.
