Performance

How long Grinch takes to decide where a link goes, and how much memory it uses. The routing workloads can be run on your Mac.

On this page

  • Method

  • Function rules
  • Footprint

Method

Release builds on an Apple M4 Max with Rust 1.95.0, median of ten runs (November 2026). The benchmarks measure URL routing only, not launching the browser or loading the page.

Run bench/run.sh to reproduce them. The workloads are in bench/configs/; setup and full results are in the benchmark notes. To time your own config, run Grinch --bench N <url>. Grinch --bench-init N measures config loading.

Declarative rules

Hostname, domain(), regex, and wildcard matchers run as native code and never call into JavaScript. When no rewrite fires, Grinch works on the original URL string without copying it.

Function rules

Your own (url, ctx) => … matchers and rewrites run in JavaScriptCore. Functions that declare a second parameter also request the context object with the opener and modifier keys. Use them when a declarative matcher or rewrite can't express the rule. "URL only" means the function takes just the URL.
